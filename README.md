# ETL OTL de Nacimientos de agua.
ETL para airflow que transforma los datos del modelo simplificado de nacimientos de agua al modelo extendio LADM_COL de nacimientos de agua.


```
.
├── config
│   └── etl_config
│       └── ms_to_ladm_zra
├── dags
│   └── ms_to_ladm_zra
├── logic
│   └── ms_to_ladm_zra
│       └── sql
│       └── resources
└── output
    └── ms_to_ladm_zra
```
